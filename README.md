# Antoine's Games

This repository contains games coded by my son, Antoine.

## Play online

- [All games](https://jak78.github.io/antoine-games/)
- [Astro Dash](https://jak78.github.io/antoine-games/astro_dash/)

## Publishing games

GitHub Pages publishes the repository root after each push to `main`, preserving
the directory structure. Each game should have its own directory containing an
`index.html` file and use relative paths for its assets.

To publish another game, add its directory alongside `astro_dash` and link to it
from the root `index.html`. Its URL will be
`https://jak78.github.io/antoine-games/<directory>/`.
